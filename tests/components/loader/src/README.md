This directory contains the assembly source and linker script used
to regenerate the loader fixtures.

The Makefile uses the GNU Arm Embedded tools
(`arm-none-eabi-as`, `arm-none-eabi-ld`, and
`arm-none-eabi-objcopy`) to assemble and link the sources with
`link.ld`. It generates ELF, binary, and object-file fixtures.
The CSV fixture is separate; it is not generated by this Makefile.

Run `make` in this directory to regenerate the fixtures. **Do not
run `make clean` unless you intend to remove the generated
fixtures.**
